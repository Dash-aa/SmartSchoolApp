# SmartSchool

> Веборієнтована інформаційна система електронного супроводу освітнього процесу в закладі загальної середньої освіти

[![Java](https://img.shields.io/badge/Java-21-orange.svg)](https://www.java.com)
[![Spring Boot](https://img.shields.io/badge/Spring%20Boot-3.2.5-brightgreen.svg)](https://spring.io/projects/spring-boot)
[![Maven](https://img.shields.io/badge/Maven-3.9-red.svg)](https://maven.apache.org)
[![License](https://img.shields.io/badge/License-Academic-blue.svg)]()

Веб-застосунок, що забезпечує єдину цифрову платформу для організації навчального процесу: від ведення електронного журналу та розкладу до комунікації між учнями, вчителями та адміністрацією школи.

Проєкт розроблено в рамках кваліфікаційної роботи бакалавра на кафедрі комп'ютерних наук Сумського державного університету.

## Можливості

Система передбачає три типи користувачів з різним рівнем доступу:

### Учень
- Перегляд тижневого розкладу занять
- Електронний щоденник з оцінками
- Перегляд домашніх завдань
- Статистика успішності (середній бал по предметах)
- Фільтрація оцінок за предметом і періодом
- Обмін повідомленнями з вчителями

### Вчитель
- Перегляд особистого розкладу
- Виставлення оцінок учням
- Створення домашніх завдань
- Перегляд списку учнів класу
- Комунікація з учнями та адміністрацією

### Адміністратор
- Управління обліковими записами користувачів
- Керування класами та навчальними предметами
- Формування навчального плану (години на тиждень)
- Призначення педагогічного навантаження
- Управління розкладом занять
- Публікація шкільних оголошень

## Технологічний стек

### Backend
- **Java 21** — мова програмування
- **Spring Boot 3.2** — фреймворк для побудови веб-застосунку
- **Spring Data JPA** — об'єктно-реляційне відображення
- **Hibernate ORM** — реалізація JPA
- **Spring Security Crypto** — хешування паролів (BCrypt)
- **H2 Database** — вбудована реляційна СУБД

### Frontend
- **Thymeleaf 3** — серверний шаблонізатор
- **Thymeleaf Layout Dialect** — наслідування шаблонів
- **Bootstrap 5.3** — CSS-фреймворк для адаптивного дизайну
- **Bootstrap Icons** — бібліотека іконок
- **Inter Font** — типографіка інтерфейсу

### Інструменти розробки
- **Apache Maven** — збирання та керування залежностями
- **Git** — система контролю версій
- **JUnit 5 + Cucumber** — модульне та BDD-тестування
- **Checkstyle, SpotBugs, Spotless** — статичний аналіз і форматування коду

## Архітектура

Застосунок реалізовано за принципом багатошарової архітектури з чітким розділенням відповідальності між шарами.

```
┌──────────────────────────────────────────┐
│  Controller Layer  (HTTP, Thymeleaf)     │
│  MainController, CabinetController, ...  │
└────────────────────┬─────────────────────┘
                     │
┌────────────────────▼─────────────────────┐
│  Service Layer  (Business Logic)         │
│  AuthService, GradeService, ...          │
└────────────────────┬─────────────────────┘
                     │
┌────────────────────▼─────────────────────┐
│  Repository Layer  (Spring Data JPA)     │
│  UserRepository, GradeRepository, ...    │
└────────────────────┬─────────────────────┘
                     │
┌────────────────────▼─────────────────────┐
│  Entity Layer  (JPA Entities)            │
│  User, Grade, Schedule, ...              │
└────────────────────┬─────────────────────┘
                     │
┌────────────────────▼─────────────────────┐
│  H2 Database  (./data/smartschool.mv.db) │
└──────────────────────────────────────────┘
```

## Швидкий старт

### Передумови

- **JDK 21** або новіша версія
- **Apache Maven 3.9+**
- Будь-який сучасний веб-браузер (Chrome, Firefox, Edge, Safari)

### Запуск

```bash
# 1. Клонувати репозиторій
git clone https://github.com/Dashaa/SmartSchoolApp.git
cd SmartSchoolApp

# 2. Зібрати проєкт
mvn clean install

# 3. Запустити застосунок
mvn spring-boot:run
```

### Доступ до системи

- **Веб-інтерфейс:** [http://localhost:8080](http://localhost:8080)
- **H2 Console:** [http://localhost:8080/h2-console](http://localhost:8080/h2-console)
    - JDBC URL: `jdbc:h2:file:./data/smartschool`
    - Username: `sa`
    - Password: *(порожнє)*

## База даних

Структура БД складається з **11 таблиць**, спроєктованих з дотриманням принципів нормалізації до третьої нормальної форми (3НФ):

| Таблиця | Призначення |
|---|---|
| `USERS` | Користувачі системи (учні, вчителі, адміністратори) |
| `CLASSES` | Навчальні класи закладу |
| `SUBJECTS` | Навчальні предмети |
| `STUDENT_CLASS` | Приналежність учнів до класів |
| `CURRICULUM` | Навчальний план (години/тиждень) |
| `TEACHER_SUBJECT_CLASS` | Педагогічне навантаження |
| `SCHEDULE` | Розклад занять |
| `GRADES` | Електронний журнал оцінок |
| `HOMEWORK` | Домашні завдання |
| `ANNOUNCEMENTS` | Шкільні оголошення |
| `MESSAGES` | Внутрішні повідомлення |

Повну ER-діаграму бази даних наведено у звіті з переддипломної практики.

## Безпека

- Паролі хешуються алгоритмом **BCrypt** перед збереженням у БД
- Розмежування доступу до функціоналу за ролями користувачів
- Захист від несанкціонованого доступу до закритих розділів
- Контекстне логування всіх HTTP-запитів через MDC (Mapped Diagnostic Context)
- Глобальна обробка винятків через `GlobalExceptionHandler`
